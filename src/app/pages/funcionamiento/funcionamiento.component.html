¿Cómo funciona el AI Security Agent?

El agente opera completamente de forma local para detectar amenazas, analizarlas y responder antes de enviar información al servidor.

📥 1. Lectura de eventos

El agente monitorea continuamente diferentes sensores del sistema operativo.

  • USB
  • Procesos
  • PowerShell
  • CMD
  • Descargas
  • Chrome
  • Archivos
  • Red
  • Extensiones

🧠 2. Análisis Local

Los eventos se correlacionan mediante reglas para calcular un nivel de riesgo.

🛡 3. Respuesta Automática

  • Finalizar procesos
  • Bloquear USB
  • Deshabilitar Internet
  • Aislar el computador
  • Cerrar aplicaciones

📡 4. Telemetría

Cuando existe un evento importante se envía un resumen al backend.
